## Option A: One-Touch Setup Script

Automatically installs Cursor's MDC rule (`.cursor/rules/engineering-squad.mdc`) and
legacy `.cursorrules`:

```powershell
# Windows (PowerShell)
.\scripts\setup-cursor.ps1
```

```bash
# macOS / Linux (Bash)
bash scripts/setup-cursor.sh
```

> 📖 Cursor limitations and usage guide: [Cursor Guide](../cursor-guide.md)
