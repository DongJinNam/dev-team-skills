# 기본 설정·Superpowers·ECC·dev-team-skills 비교 설계 초안

실행 전 설계 기록이다. 승인된 12회 실행은 완료했으며, 실제 측정 범위·결과·사후 검사는 [최종 보고서](../../decisions/2026-11-07-four-arm-results.md)를 따른다. 아래 69개 테스트와 미입증 판정은 설계 당시 상태다. 후속 전체 회귀시험은 79개이며, 일반적 우수성·비열등성은 여전히 미입증이다.

## 질문과 현재 판정

dev-team-skills의 우수성과 비열등성(허용한 차이보다 뒤처지지 않음)은 모두 미입증이다.
같은 모델·환경에서 네 조건을 분리해 공통 과제로 측정하고, 작은 예비 실험은 다음 실험을 설계하는 자료로 사용한다.
현재 검증한 설치 성공 3/3과 단위 테스트 69/69는 타 스킬 대비 작업 성과를 측정하지 않았기 때문이다.

## 사용자 요청과 실행 상태

- 2026-11-07: 현재 사용하는 모델 기준으로 기본 스킬·Superpowers·ECC와 dev-team-skills 성과 비교 요청.
- 로컬 `~/.codex/config.toml`에서 `model = "gpt-6-astra"`, `model_reasoning_effort = "high"` 확인. 이는 CLI 설정이며 현재 대화의 실제 모델 ID를 검증한 것은 아니다. 모든 실행에 동일 모델/추론 설정을 명시하고 실행 메타데이터를 확인한다. 다른 모델로 자동 대체하지 않는다.
- ECC 후보: 공식 [affaan-m/ECC](https://github.com/affaan-m/ECC), Everything Claude Code. Superpowers 공식 출처: [obra/superpowers](https://github.com/obra/superpowers). 2026-11-07 원문 확인; 인기도·스킬 개수는 성과 지표로 쓰지 않는다.
- 사용자는 4조건 × 3과제 = 12회, 회당 최대 5분, 별도 API 결제 없이 현재 계정 사용량으로 실행하는 예비안에 “오케이”라고 승인했다. `codex login status`에서 ChatGPT 로그인을 확인했다. 인증 문제·별도 API 결제가 필요하면 중단한다.

## 조건 정의

| 조건 | 유지할 내용 | 배제할 내용 |
| --- | --- | --- |
| 기본 | Codex 기본 시스템 지침·같은 도구·안전 권한 | 추가 세 패키지와 그 전역/프로젝트 규칙 |
| Superpowers | 기본 + 고정 버전 Superpowers | ECC, dev-team-skills |
| ECC | 기본 + 고정 버전 ECC의 Codex용 지원 구성 | Superpowers, dev-team-skills |
| dev-team-skills | 기본 + 현재 후보 파일의 고정 snapshot | Superpowers, ECC; COMBINED로 실행하지 않음 |

현재 대화에는 여러 스킬과 저장소 AGENTS.md가 이미 적용돼 있다. 이 대화의 답변 또는 같은 지침을 물려받은 서브에이전트 결과를 ‘기본 설정’ 성적으로 쓰지 않는다. 격리된 실행 설정·작업 디렉터리·새 세션에서 시작하고 실제 로드한 규칙/스킬 출처를 확인한다. 숨은 정책 혼입이 있으면 해당 표본의 비교 유효성을 보류한다.

패키지 전체 구성 효과를 측정할지 지침만 측정할지 구분한다. 우선 Codex에서 안전하게 사용할 수 있는 지침 구성을 평가하고 hook/MCP/외부 서비스 실행 여부를 기록한다. 제외된 기능이 있으면 ‘ECC 전체 성능’이라고 일반화하지 않는다. 패키지 권한이 다르면 별도 조건으로 둔다. 파일 해시·배포 버전·설치 방식과 실제 로드 파일을 실행 전에 고정한다.

## 공통 과제와 채점 초안

| 과제 | 관측할 결과 | 공통 검사 |
| --- | --- | --- |
| 버그 수정 | JSONL 집계기의 잘못된 결과와 입력 오류 처리 수정 | 정상·빈 입력·잘못된 타입·중복 ID·UTF-8·회귀 검사 |
| 작은 기능 | 기존 함수에 페이지네이션 추가 | 기본값·경계값·안정 순서·기존 인터페이스 보존 |
| 문서 수정 | 실제 CLI와 어긋난 설치 안내 수정 | 존재하는 명령·경로·실행 증거와 미검증 표시·무관한 코드 불변 |

실제 입력·비공개 수용 테스트·시간 제한·정답 판정은 모델 실행 전에 고정한다. 자사 역할명·승인 형식·보고서 문장 수를 다른 패키지의 오답 기준으로 쓰지 않는다. 필요한 사용자 요구·시작 합의·승인 권한은 동일 초기 프롬프트로 제공하고, 추가 질문이 필요하면 개입 횟수와 대기 시간을 기록한다. 중간 답변은 사전 답안표로 동일하게 제공하며 임의 힌트는 금지한다.

실행 순서는 과제별로 순환해 특정 조건의 선후행 이점을 줄인다. 정답 테스트를 에이전트에게 노출하지 않고, 별도 검토자는 조건명을 가린 산출물의 범위·안전·유지보수성을 확인한다. 성공/실패/시간초과/중단을 모두 보존한다.

## 보고할 지표

- 주 지표: 숨겨진 공통 수용 테스트와 독립 검토를 모두 통과한 과제 수 / 시작한 전체 과제 수.
- 첫 시도: 추가 사용자 안내 없이 완료한 과제 수 / 전체 과제 수.
- 비용: 전체 호출(부모/하위/재시도/검토)의 입력·출력 토큰, 성공 과제당 사용량. 계측 누락은 UNMEASURED.
- 시간: 시작부터 종료까지 초, 사용자 대기 시간 별도 표시. 실패가 빨리 끝났다고 효율이 좋다고 판단하지 않는다.
- 결함: 회귀·범위 밖 수정·근거 없는 완료 주장 건수, 추가 안내/재시도 횟수.
- 설치·스킬 발견·실제 호출은 작업 성과와 별도 행으로 표시한다.

12회는 조건당 3과제의 예비 관찰이다. 각 조건 3/3이 나와도 동등성·비열등성·일반적 우수성을 증명하지 않는다. 본 실험의 과제 수·반복 수·허용 열등 폭·개선 목표·통계 분석은 예비 결과를 보고 사전 확정한다. ‘통계적으로 차이를 찾지 못함’을 ‘같음’으로 바꾸지 않는다.

## 산출물과 남은 게이트

예비 결과는 과제별 원본 로그·모델 ID·정책/과제/채점기 해시·독립 검토와 함께 저장한다. 기존 `evals/compare_outcomes.py`로 기본/Superpowers/ECC 각각과 dev-team-skills를 짝지어 집계하고, `compare_usage.py`로 전체 사용량·동일 품질 비교를 보완한다. 집계만으로 자동 우수성 판정을 내리지 않는다.

실행 범위·인증 방식·공통 과제/채점기를 확정했다. [실행 계획](../plans/2026-11-07-four-arm-pilot.md)에 패키지 고정·격리·생성 코드 사전 검토·계측 범위를 기록한다. 인증·별도 결제·권한 밖 도구가 필요하면 해당 실행을 멈춘다.
