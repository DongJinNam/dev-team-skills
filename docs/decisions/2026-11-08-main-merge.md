# 최신 main 병합 충돌 해결

PR #21 브랜치에 main `ff2ca59e3269d645a1012aa01a2ebe927abf86f4`를 병합하고 한국어·영어 README의 충돌을 해결했다.
main의 Antigravity·Cursor 안내와 시작 절차 개선을 유지하면서 Codex 수정·검증 범위·실험 원본을 보존하고 native 스킬 복사본을 정본에 맞췄다.
정책이 달라져 기존 판단 기록은 새 결과로 재사용할 수 없으므로 병합된 정책의 응답과 독립 검토를 별도로 기록한다.

## 해결 기준

- README는 기존 실측 결과와 한계를 유지하고 main의 추가 집계기·설치 안내를 연결했다. 입력 수치 재계산과 실제 모델 실행 증거를 구분하며 근거 없는 호스트 전체 공식 검증 표현을 제거했다. main의 추가 데이터·도구 파일은 삭제하거나 실측으로 재분류하지 않았다.
- main에서 추가한 `.agents/skills`는 복사본이므로 자동 병합만으로 정본 수정이 전파되지 않았다. 달라진 12개 파일을 동기화해 UTF-8 읽기·증거 계약·BOM 수정과 main의 시작 절차 변경을 함께 반영했다.
- `tests/test_skill_mirror.py`는 실제 스킬 디렉터리의 파일 목록과 바이트 일치를 확인한다. 루트 호환 진입 파일과 그 공유 리소스는 native 스킬 디렉터리가 아니므로 대상에서 구분한다.
- 기존 12회 실험의 과제·실행기·채점기 및 80개 증거 파일은 그대로 보존한다. 기존 판단 기록도 덮어쓰지 않으며, 변경된 정책으로 `STALE`이 되는 것은 정상적인 증거 만료다.
- main의 Cursor 설치 스크립트에 대한 기존 덮어쓰기/동일 경로 동작은 이번 충돌 해결에서 변경하지 않았다. 실제 Antigravity·Cursor 설치 성공을 새로 주장하지 않는다.

## 검증

- 전체 단위 테스트 **85/85 PASS**, 31.449초. 테스트 안의 모델 호출 출력은 mock 기반이며 추가 성능 실험이 아니다.
- Windows PowerShell·Git Bash 패키지 검사 각각 PASS. 독립 보안 담당도 mirror 검사를 별도 실행해 PASS를 확인했다.
- 전체 staged diff의 공백 검사는 main에서 유입된 기존 문서·스크립트 공백을 지적한다. PR base 대비 남은 경고는 mirror에 복제한 `superpowers-compatibility.md` 및 `_en.md`의 Markdown hardbreak 4행이다. 정본과 바이트 일치 계약에 따라 유지하며 전체 공백 검사 PASS라고 보고하지 않는다. 해당 두 mirror 파일을 제외한 `git diff --check origin/main`은 PASS다.
- 최종 판단 회귀와 커밋 대상 보안 검토는 새 기록 및 PR #21의 최신 head/base 보고서를 따른다. 이전 커밋의 보안 PASS를 새 병합 입력의 승인으로 사용하지 않는다.

## 판단 회귀의 범위

새 actor `/root/merge_regression_actor`에게 현재 정책과 기존 19개 공개 질문·응답 계약만 제공했다. 기대 답안·이전 응답·테스트는 제공하지 않았으며, 응답 값은 수정하지 않고 [새 기록](../../evals/runs/2026-11-08-main-merge.json)에 보존한다. `/root/eval_review`가 응답과 정책 해시에 연결한 별도 의미 검토를 담당한다. 한 문맥의 판단 응답이며 실제 시나리오 실행·성능 개선 증거가 아니다.

최종 독립 의미 검토와 현재 정책 replay는 각각 **19/19 PASS**이며 `tool_execution=NOT_OBSERVED`다. CI는 이 새 기록을 재검사하도록 갱신했다. 고정 실험의 소스 해시와 80개 증거 파일도 병합 전 커밋과 일치함을 재확인했다.

독립 검토자가 지적한 한계도 유지한다. 기존 19개에는 최초 요청의 기대효과·중단 조건이 모두 주어진 시작 상황이 없어 main의 Adaptive Kickoff 자체를 검증하지 않는다. main 본문과 역할 계약의 시작 조건 표현 차이는 이번 충돌 해결에서 수정하지 않았으며, 회귀 PASS를 그 경계의 모순 해소로 확대하지 않는다.
