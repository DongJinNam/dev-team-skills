# 자동화 Phase 1 결정 기록: 검수 패킷 초안 자동화 (observe)

- 날짜: 2026-11-11
- 근거 설계: 자동화 파이프라인 설계안(요구사항 분석, 개선안 비교, 단계적 하이브리드 선택)의 Phase 1. 병목 실측은 PR #30·#31 진행 기록 기준이다.

## 결정

보안 검수 패킷 초안을 GitHub Actions로 자동 생성해 PR 코멘트로 게시·갱신한다. `scripts/security_packet.py`가 base..head diff에서 변경 파일과 blob, 캡처 STALE 가능성, 등급 제안을 뽑고, 제출자가 검증 근거를 채워 제출한다.

## 승격 절차 적용

- 이 자동화는 `docs/automation-promotion.md`의 observe 단계로 시작한다. 코멘트 게시까지만 하고, 판정·제출·머지는 하지 않는다.
- 담당자는 Tech Lead다. assist 승격은 관찰 기록(20회 실행 또는 2주)과 오탐 집계가 쌓인 뒤 별도 PR로 판단한다.
- 캡처 STALE 표시는 가능성 경고다. 실제 STALE 여부는 기존 CI 재생 검사가 판정한다.

## 기각한 대안

- 패킷 자동 제출: 판정 게이트의 제출 행위까지 자동화하면 사람이 내용을 확인하지 않은 초안이 검수에 들어간다. observe 단계 범위를 넘는다.
- 자동 머지 조건 표시 이상의 개입: 머지 가능 여부는 판정과 사용자 지시의 결합이라 자동화가 돕지 않는다.
- 외부 오케스트레이션 도구 도입: 독립 검수 계약과의 정합성 검증 비용이 현 단계 이득보다 크다.
